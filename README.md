1. ادفع محتويات هذا المجلد إلى الفرع `main`.
2. من Settings ← Pages اختر `Deploy from a branch` ثم `main` و`/ (root)`.
3. الرابط: https://bakinou-24.github.io/ecusoft-catalog/
